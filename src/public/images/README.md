# 📁 Folder Gambar & Logo Aplikasi (/src/public/images/)

Folder ini digunakan untuk menyimpan aset visual dan logo aplikasi Educamp.
Semua file di dalam folder ini otomatis dapat diakses oleh browser melalui URL `/images/<nama-file>`.

---

## 🖼️ Rekomendasi Penamaan File Logo

Untuk mempermudah pemanggilan di HTML/CSS/Canvas:

| Nama Rekomendasi File | Varian Logo | Rekomendasi Penggunaan |
| :--- | :--- | :--- |
| `logo-educamp.png` | **Full Color** (`Logo Educamp 2026_tagline.png`) | Header utama, hero card, layar pembuka |
| `logo-educamp-white.png` | **White Tagline** (`Logo Educamp 2026_tagline_white.png`) | Layar gelap: Proyektor Arena, Leaderboard, Tablet Controller |
| `logo-educamp-black.png` | **Black Tagline** (`Logo Educamp 2026_tagline_black.png`) | Cetak sertifikat / dokumen berlatar putih |

---

## 📍 Cara Menaruh File Logo
Silakan simpan file gambar yang Anda upload ke folder ini:
`/src/public/images/`
